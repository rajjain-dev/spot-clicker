# Phase one

Deliver one compact, rechargeable Bluetooth clicker with felt save feedback and a local iPhone map.

- Single → Liked; double → Want to go; hold → undo latest real capture within 10 minutes.
- Phone supplies GPS; success feedback follows durable storage. Disconnected clicks are discarded; uncertain results require checking the app before retrying.
- App includes map/list/detail, editing, CSV export, and offline local storage. Hardware and pocket behavior require physical checks.
- Complete when button, motor, battery/charging, enclosed fit, reconnection, pocket use, and walking tests pass [BUILD_PLAN](docs/BUILD_PLAN.md).
- Later: business identification, AI, cloud sync, and proximity reminders. Camera Pendant is separate.

Class evidence: tester/task/observation/design change and a reproducible demo. Raj directed that class deadlines should not constrain the MVP.
